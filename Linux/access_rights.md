# Linux - права доступа

## Что такое права доступа

**Права доступа** определяют, кто может читать, изменять или выполнять файл, а также просматривать содержимое каталога.

В Linux выделяют три категории пользователей:

- `u` - User: владелец файла.
- `g` - Group: группа файла.
- `o` - Others: остальные пользователи.
- `a` - All: все категории.

**Именно 3, "a" не считается как категория пользователей, a = ALL  
Не путать!**

## Типы прав

| Символ | Право | Для файла | Для каталога |
|---|---|---|---|
| `r` | Read (4) | Читать содержимое | Просматривать имена файлов |
| `w` | Write (2) | Изменять содержимое | Создавать, удалять и переименовывать записи |
| `x` | Execute (1) | Выполнять файл | Проходить через каталог и обращаться к объектам внутри при наличии других необходимых прав |

## Просмотр прав

Команда:

```
ls -l
```

Пример вывода:

```
-rwxr-xr-- 1 user developers 1200 Oct 18 script.sh
```

Разбор:

```
- | rwx | r-x | r--
  |  u  |  g  |  o
```

- Первый символ обозначает тип объекта: `-` - обычный файл, `d` - каталог.
- `rwx` - права владельца.
- `r-x` - права группы.
- `r--` - права остальных пользователей.

В этом примере владелец может читать, изменять и выполнять файл; группа может читать и выполнять; остальные могут только читать.

## Изменение прав - chmod

Команда `chmod` изменяет права доступа.

### Символьная запись

Добавить право на выполнение владельцу:

```
chmod u+x script.sh
```

Убрать право на запись у группы:

```
chmod g-w script.sh
```

Установить права на чтение всем:

```
chmod a+r file.txt
```

### Числовая запись

Права обозначаются числами:

- `r = 4`
- `w = 2`
- `x = 1`

Числа складываются для каждой категории.

| Число | Права |
|---|---|
| `7` | `rwx` |
| `6` | `rw-` |
| `5` | `r-x` |
| `4` | `r--` |
| `0` | `---` |

Примеры:

```
chmod 755 script.sh
chmod 644 file.txt
chmod 700 private.sh
```

- `755` → владелец `rwx`, группа `r-x`, остальные `r-x`
- `644` → владелец `rw-`, группа `r--`, остальные `r--`
- `700` → только владелец имеет права `rwx`

## Как это работает?

Цифры складываются, чтобы получить нужный набор прав

```
Расчёт	    Результат	        Права
4 + 2 + 1     	7	         rwx
4 + 2	        6	         rw-
4 + 1	        5	         r-x
4	        4	         r--
2 + 1     	3	         -wx
0          	0	         ---
```

## Изменение владельца - chown

Команда `chown` изменяет владельца файла или каталога.

```
sudo chown user file.txt
```

Изменить владельца и группу:

```
sudo chown user:developers file.txt
```

Рекурсивно изменить владельца для каталога и его содержимого:

```
sudo chown -R user:developers directory/
```

Параметр `-R` применяет изменение ко всему содержимому каталога

## Права доступа к каталогам

Для каталогов права работают иначе, чем для обычных файлов:

- `r` - позволяет просматривать список имён внутри каталога.
- `w` - позволяет изменять записи каталога, например создавать и удалять файлы, если также есть право `x`.
- `x` - позволяет проходить через каталог и обращаться к объектам внутри при наличии необходимых прав.

Например, без `x` пользователь может не иметь возможности открыть файл по его пути, даже если знает его имя.

## Важные моменты безопасности

- Не выдавай права `777` без необходимости: они позволяют всем читать, изменять и выполнять файл, а для каталога - изменять его содержимое и проходить через него.
- Не запускай команды с `sudo`, если не понимаешь, зачем нужны повышенные привилегии.
- Права доступа помогают ограничивать действия пользователей, но сами по себе не заменяют другие механизмы безопасности.
- Для просмотра владельца, группы и прав используй `ls -l`.

## Главное

- `ls -l` - посмотреть права.
- `chmod` - изменить права.
- `chown` - изменить владельца и группу.
- `r = 4`, `w = 2`, `x = 1`.
- `755` - владелец может всё, группа и остальные могут читать и выполнять.
- `644` - владелец может читать и изменять, остальные - только читать.
