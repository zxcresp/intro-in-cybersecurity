# Interaction with Linux through the Terminal

Some of the most default commands that you will use throughout your entire time using Linux:

```
pwd
ls
cd
clear
history
man
which
whoami
wget
apt-get
```

* <b>pwd</b> - prints the full path to the current working directory where you are currently located
* <b>ls</b> - viewing the contents of directories - a list of files and folders located in them
* <b>cd</b> - navigating between folders (directories)
* <b>clear</b> - clears the terminal screen of accumulated text and output
* <b>history</b> - used to view, manage, and re-run commands previously entered in the terminal
* <b>man</b> - shows a detailed description of a program, its purpose, and its author; it also shows how to properly run the command and which arguments to pass to it
* <b>which</b> - allows you to quickly find out which exact directory the specified program is launched from
* <b>whoami</b> - displays the name of the current active user running the session
* <b>wget</b> - a utility for downloading files from the internet using a link
* <b>apt-get</b> - a command for installing, updating, and removing programs in the system

  ```
    										Examples of using all commands are shown below:
  ```

1. pwd

```
user@host:~$ pwd
  
/home/user/documents
```

2. ls (suppose that your home directory contains a photo named media.png and a video named astral.mp4)

```
user@host:~$ ls

media.png astral.mp4
```

3. cd (for example, you want to navigate to the Downloads folder)

```
user@host:~$ cd Downloads

user@host:~/Downloads$ 
```

4. clear

```
# Before:

user@host:~$ pwd
/home/user
user@host:~$ ls
media.png  astral.mp4
user@host:~$ clear

# After:

user@host:~$
```

5. history

```
user@host:~$ history
    1  pwd
    2  ls
    3  cd Downloads
    4  clear
    5  history
```

6. man (to exit the help mode, press "q")

```
user@host:~$ man ls

LS(1)                            User Commands                           LS(1)

NAME
       ls - list directory contents

SYNOPSIS
       ls [OPTION]... [FILE]...

DESCRIPTION
       List information about the FILEs (the current directory by default).
```

7. which

```
user@host:~$ which python3
/usr/bin/python3

user@host:~$ which ls
/usr/bin/ls
```

8. whoami

```
user@host:~$ whoami  
user
```

9. wget

```
user@host:~$ wget https://example.com/file.zip
```

10. apt-get

```
user@host:~$ sudo apt-get install nmap
```
