# Взаимодействие с Linux через терминал

Одни из самых дефолтных команд, которыми вы будете пользоваться на протяжении всего использования Linux:

```
pwd
ls
cd
clear
history
man
which
whoami
wget
apt-get
```

* <b>pwd</b> - выводит в терминале полный путь к текущей рабочей папке, в которой вы сейчас находитесь  
* <b>ls</b> - просмотр содержимого каталогов - списка файлов и папок, которые в них находятся  
* <b>cd</b> - переход между папками (каталогами)  
* <b>clear</b> - очистка экрана терминала от накопившегося текста и вывода  
* <b>history</b> - для просмотра, управления и повторного запуска ранее введенных в терминале команд  
* <b>man</b> - показывает подробное описание программы, ее назначение и автора, также показывает как правильно запускать команду и какие аргументы ей передавать  
* <b>which</b> - позволяет быстро узнать, из какой именно папки запускается указанная программа  
* <b>whoami</b> - для вывода имени текущего активного пользователя, выполняющего сеанс  
* <b>wget</b> - утилита для скачивания файлов по ссылке из интернета
* <b>apt-get</b> - команда для установки, обновления и удаления программ в системе

  												Ниже приведены примеры работы всех команд:
1) pwd
  ```
  user@host:~$ pwd
    
  /home/user/documents
  ```

2) ls (допустим, у вас в домашней директории есть фото с названием media.png и видео astral.mp4)
```
user@host:~$ ls

media.png astral.mp4
```

3) cd (например, вы хотите перейти в папку Downloads)
```
user@host:~$ cd Downloads

user@host:~/Downloads$ 
```

4) clear
```
# До:

user@host:~$ pwd
/home/user
user@host:~$ ls
media.png  astral.mp4
user@host:~$ clear

# После:

user@host:~$
```

5) history
```
user@host:~$ history
    1  pwd
    2  ls
    3  cd Downloads
    4  clear
    5  history
```

6) man (для выхода из режима справки нужно нажать "q")
```
user@host:~$ man ls

LS(1)                            User Commands                           LS(1)

NAME
       ls - list directory contents

SYNOPSIS
       ls [OPTION]... [FILE]...

DESCRIPTION
       List information about the FILEs (the current directory by default).
```

7) which
```
user@host:~$ which python3
/usr/bin/python3

user@host:~$ which ls
/usr/bin/ls
```

8) whoami
```
user@host:~$ whoami  
user
```

9) wget
```
user@host:~$ wget https://example.com/file.zip
```

10) apt-get
```
user@host:~$ sudo apt-get install nmap
```
