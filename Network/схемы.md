# Diagrams with examples
```
Application
	↓
   HTTP
	↓
   TCP
	↓
    IP
	↓
 Ethernet
	↓
Physical medium
```

For example, when you open a website:
```
Browser
   ↓
HTTP/HTTPS
   ↓
  TCP
   ↓
IPv4/IPv6
   ↓
Ethernet
   ↓
Wi-Fi / cable
```
On the receiving end, the process happens in reverse:
```
Wi-Fi / cable
	 ↓
  Ethernet
	 ↓
 IPv4/IPv6
	 ↓
	TCP
	 ↓
	HTTP
	 ↓
  Browser
```
And this is called encapsulation/decapsulation
