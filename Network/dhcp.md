# DHCP (Dynamic Host Configuration Protocol)

**DHCP** - сетевой протокол, который автоматически назначает устройствам IP-конфигурацию.

## Что назначает DHCP

* IP-адрес
* Маску подсети
* Основной шлюз (Default Gateway)
* DNS-серверы
* Время аренды IP-адреса (Lease Time)

## Как работает DHCP

DHCP использует процесс **DORA** из четырёх этапов:

1. **Discover** - клиент ищет DHCP-сервер.
2. **Offer** - сервер предлагает IP-адрес.
3. **Request** - клиент запрашивает предложенный адрес.
4. **ACK (Acknowledgment)** - сервер подтверждает выдачу адреса.

```
Client → Discover → DHCP Server
Client ← Offer    ← DHCP Server
Client → Request  → DHCP Server
Client ← ACK      ← DHCP Server
```

Первоначальные сообщения обычно передаются через broadcast, поскольку клиент ещё не знает свою сетевую конфигурацию.

## Порты DHCP

DHCP для IPv4 использует UDP:

* **UDP 67** - сервер.
* **UDP 68** - клиент.

## DHCP Lease

**Lease** - аренда IP-адреса на определённое время. По истечении срока клиент пытается продлить аренду. Адрес может быть выдан другому устройству после освобождения или истечения аренды.

## DHCP и статический IP

* **DHCP** - конфигурация назначается автоматически.
* **Статический IP** - конфигурация задаётся вручную или через постоянную DHCP-резервацию.

## Пример

Роутер выполняет роль DHCP-сервера и выдаёт компьютеру:

```
IP address:      192.168.1.100
Subnet mask:     255.255.255.0
Default gateway: 192.168.1.1
DNS server:      192.168.1.1
```

Компьютер получает настройки автоматически и может взаимодействовать с другими устройствами сети.

## DHCP и безопасность

* **Rogue DHCP Server** - неавторизованный DHCP-сервер, который может выдавать неправильные сетевые настройки.
* **DHCP Starvation** - исчерпание пула доступных IP-адресов множеством запросов.
* Для защиты в управляемых коммутаторах используют **DHCP Snooping** и ограничение доверенных DHCP-портов.

## DHCP-сервер
Это устройство или программа, которая автоматически выдаёт подключённым устройствам настройки сети, чтобы они могли взаимодействовать друг с другом и выходить в интернет
